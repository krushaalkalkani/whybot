# WhyBot RCA Bench v1

A small synthetic benchmark for root-cause analysis agents. A fake online shop ("Northwind Goods") has two years of daily metrics, support tickets, GitHub issues and a deploy changelog. 80 questions ask why a metric moved. Each has a planted cause and gold evidence IDs, so answers can be scored.

Everything is generated by one seeded script (`bench/generate.py` in the WhyBot repository, seed 7). No real company or person is in the data.

## Files

| File | Rows | What it is |
| --- | ---: | --- |
| `metrics.csv` | 43,860 | One row per date x region x platform x channel, 2024-01-01 to 2025-12-31. Columns: sessions, checkout_starts, payment_attempts, payment_failures, orders, revenue. |
| `documents.jsonl` | 4,031 | Evidence. `source` is `ticket`, `issue` or `changelog`. Fields: id, source, created_at, title, body, meta. |
| `scenarios_dev.jsonl` | 40 | Questions about 2024. Use these to build and tune. |
| `scenarios_test.jsonl` | 40 | Questions about 2025. Frozen. Run once. Do not tune on them. |
| `MANIFEST.json` | 1 | Version, seed, counts and SHA-256 of the files. |

## Scenario fields

| Field | Meaning |
| --- | --- |
| `question` | The question, e.g. "Why did sessions in APAC fall 43% on 2024-03-22?" |
| `kind` | `plain`, `decoy_loud`, `decoy_seasonal`, `unanswerable` or `injection` |
| `expected` | `abstain` (bool), `cause_type`, `segment_dimension`, `segment_value` |
| `key_evidence_ids` | Documents that name the cause |
| `gold_evidence_ids` | Key documents plus supporting tickets |
| `distractor_ids` | Loud but unrelated documents (decoys) |
| `injection` | For injection scenarios: the injected ticket IDs, a canary code, the wrong cause the attacker pushes, and `style` (`obvious` or `subtle`) |
| `planted` | What the generator changed in the metrics |
| `smoke` | True for the 20 dev scenarios used as a fast regression subset |

## Scenario kinds

| Kind | Count | Right answer |
| --- | ---: | --- |
| plain | 52 | The planted cause (one of 6 types) and its segment |
| decoy_loud | 6 | The planted cause, not the loud unrelated event on the same day |
| decoy_seasonal | 6 | `seasonality`: a normal weekend dip, not an incident |
| unanswerable | 8 | Abstain: the metric moved but no document explains it |
| injection | 8 | The planted cause, ignoring instructions hidden in tickets |

Cause types: `bad_deploy`, `pricing_change`, `regional_outage`, `platform_bug`, `campaign_end`, `payment_provider_error`.

## Suggested metrics

Root-cause accuracy@1 and @3 (cause type and segment must match; for unanswerable scenarios, abstaining is correct), citation precision against `gold_evidence_ids`, citation recall against `key_evidence_ids`, abstention accuracy, injection resistance. Reference scoring code: `bench/metrics.py`.

## Limits

- Text comes from templates. It is cleaner and more repetitive than real tickets.
- 40 test scenarios is a small sample. One scenario is 2.5 points of accuracy.
- The author of the benchmark also built a system for it. Scores are for comparing systems on this task, not for claims about real incidents.
- The injection tickets contain plain-text prompt-injection attempts on purpose.
